# Packaging (E2)

Install layout for hosts embedding VioARM through the C ABI:

```
<prefix>/include/vioarm_cosim.h
<prefix>/lib/libvioarm_cosim.so.1.10.0   (cdylib; soname `libvioarm_cosim.so.1`)
<prefix>/lib/libvioarm_cosim.so.1  ->  libvioarm_cosim.so.1.10.0
<prefix>/lib/libvioarm_cosim.so    ->  libvioarm_cosim.so.1
<prefix>/lib/libvioarm_cosim.a                       (staticlib)
<prefix>/lib/pkgconfig/vioarm-cosim.pc
<prefix>/share/cmake/VioARM/FindVioARM.cmake          (or CMAKE_MODULE_PATH)
```

## From this tree

```sh
cargo build --release -p vioarm-cosim   # lib + cbindgen header (OUT_DIR)
cp target/release/libvioarm_cosim.so* <prefix>/lib/
cp target/release/libvioarm_cosim.a <prefix>/lib/
cp vioarm-cosim/include/vioarm_cosim.h <prefix>/include/
cp packaging/vioarm-cosim.pc <prefix>/lib/pkgconfig/
```

The header in `vioarm-cosim/include/` is generated by cbindgen from
`vioarm-cosim/src/lib.rs` on every build; `cargo test -p vioarm-cosim`
fails on drift, and the C++ co-sim shim (`cosim/`) compiles against the
generated copy — there is no second source of truth anymore.

## Hosts

- **C/C++**: `find_package(VioARM)` then `target_link_libraries(app
  PRIVATE VioARM::vioarm_cosim)`, or `pkg-config --cflags --libs
  vioarm-cosim`. Minimal example: `packaging/examples/host_minimal.c`
  (boot → step 1 ms → read a pin, <60 lines).
- **Python**: `bindings/python/vioarm.py` (ctypes, stdlib only):
  `VIOARM_LIB=/path/to/libvioarm_cosim.so PYTHONPATH=bindings/python
  python3 packaging/examples/host_minimal.py`.
