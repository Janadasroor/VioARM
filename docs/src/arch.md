# Architecture

- `Machine` + `SystemMemory` + `FlatMemory` + `Peripheral` trait
- `RegisterFile` + `Behavior` + SVD tables (`vioarm-svd`)
- `DWT` `cyccnt`, `SCB` `MPU` `TrustZone`, `FPU` softfloat; `M33` mainline = full `Thumb-2` + `DSP` + `FPv5-SP`, diffed vs `mps2-an505`
- Determinism: single-threaded, `BTreeMap`, no `HashMap` in state
- Clocks: family-aware `RCC` (`F1`/`F4`/`H7` layouts, `SW`+PLL → `SYSCLK` Hz, `H7` `TIMPRE`) → shared `ClockState` → `APB` timer-kernel ratios (×2/×4 rules, exact fractional carry) + `SysTick` `CLKSOURCE` (`HCLK` or `HCLK`/8, `D1CPRE` on `H7`); `FLASH_ACR` wait states + `AXI/FMC` fetch latency priced in core `cyccnt`. `HSE` assumed `8M` (`25M` `H7`); downstream clock gating deliberately unenforced
- Per-Dname model: 32 donor `PERIPHERALS` + removal deltas (`per_dname.rs`, 505 Dnames), filtered at runtime — no per-chip table copies; `F2`/`F7`/`G0` donors are own-`SVD` generation tables (residual per-window diffs inventoried in `Known limitations`)
- DMA request lines: `F1` channels (`DmaRequests` mailbox — `ADC1`→ch1, `TIM2_UP`→ch2, `SPI1` TX/RX→ch3/ch2, `USART` baked routes, wired on `F103`+`F107`) vs `F4` streams (one burst per asserted request, memory-to-memory stays optimistic; wired on every `F4`/`F2`/`F7`/`H7` board under one stream convention — `USART1` on `DMA2 S0/S1`, `USART2/3` on `DMA1 S2/S3`, `UART4` on `DMA1 S4/S5`, `UART5` on `DMA2 S6/S7`, `USART6` on `DMA2 S2/S3`, `TIM1/2/4` update on `DMA1 S6`, `ADC` on `DMA1 S7`, `SPI1` on `DMA1 S0/S1`, `SPI2/3` on `DMA2 S4/S5`; nonzero `CHSEL` remaps a stream to a channel bit, nonzero `H7` `DMAMUX1` `DMAREQ_ID` remaps it to a request input — zero keeps the stream convention; `HTIF`/`TEIF`/`FEIF`/`DMEIF` + `CIRC`/`DBM` + true `FTH` FIFO modeled)
- `LPTIM` (compare/autoreload matches, prescaler, one-shot, external-edge counting; encoder/capture latch-only) on `F2`/`F7`/`G0`/`G4`/`L4`/`H7`/`M33` boards; `FDCAN` full `M_CAN` (`FDCAN1` on `H743` against verified `SRAMCAN`) + cut-down (`G0`/`G4`/`M33` on verified CAN RAM) + stub elsewhere, loopback-proven board-level (`fdcan_boards.rs`)
- `CAN` error model (both controllers, `+8` per injected error, `-1` per success): bxCAN `TEC`/`REC` in `ESR` with `EWGF`/`EPVF`/`BOFF`, sticky `LEC`, `TERR` on failed TX, bus-off freezing TX and recovering after 128 accepted frames (TX pacing stays `BTR`-derived); FDCAN `ECR` (`TEC`/`REC`+`RP`/`CEL`) + `PSR` (`LEC`/`EP`/`EW`/`BO`, destructive reads settling next tick), error-destroyed RX, `DAR` abort vs retry, TX event FIFO (`EFC` elements, watermark/full/lost, `TXEFA` acknowledge), `TXBCR` cancellation of unfetched buffers (`TXBCF`+`TCF`, late cancels fail). Deliberately unmodeled: FDCAN bit-timing (mailbox round-trip pacing), data-phase errors, timestamps, clock-stop/power-down. Proven by error-injection suites in `can.rs`/`fdcan.rs` lib tests
- `SDIO` paced data path over a 1 MiB card image: `CLKCR`-derived tick pacing (`CLKDIV`, `WIDBUS` 1/4/8, `CMD6` high-speed doubling), `CMD18`/`CMD25` multi-block runs with `DATAEND` at `CMD12`, per-block CRC-16 on reads, `DTIMER` deadline (`DTIMEOUT` + abort), `CTIMEOUT` on clashing starters, `CMD13` card-state polling, `CCRCFAIL`/`DCRCFAIL` by injection. Deliberately unmodeled: command-CRC stimulus, FIFO depth bounds, erase/protect/lock commands. Proven by multi-block write→read compare + exact-tick pacing + timeout/clash tests in `sdio.rs` lib tests
- `USART` full duplex: `TXE`/`TC`/`RXNE` synthesis, host RX injection, `RXNEIE` level IRQ + RX DMA lines on `F1`/`F4`/`H7` tables; receive errors follow silicon — `ORE` on overrun (first byte kept), `FE`/`PE` via stimulus bits 9/10, `SR`-then-`DR` clear sequence on `F1` / `ICR.ORECF/FECF/PECF` on new-gen, error IRQs via `CR3.EIE` / `CR1.PEIE`. Deliberately unmodeled: `NE`, `OVRDIS`, `RE` gating (injection stays order-free). Loopback-proven with real firmware on `f103` + `h743` (`usart_loopback.rs`)
- `SPI` error model + pair proof: `OVR` latches when a frame completes (master) or arrives (slave) with `RXNE` set — old byte kept, newcomer lost; `UDR` latches when a controller frame arrives with nothing staged; both clear in the `SR`-then-`DR` sequence and assert via `CR2.ERRIE` (shared with `MODF`/`CRCERR`). Master NSS output (`SSOE`) and slave `TXE` consume deliberately unmodeled (documented in `spi.rs`). Proven by 5 lib tests + real C-firmware controller/peripheral exchange over `Fabric::link_spi` (`f103`+`f107`, both directions, `UDR` on the unstaged first frame, `OVR` on unread frames — `spi_pair_hand.rs`)
- `I2C` master transaction set: `START`/`STOP`/`SB`/`ADDR`/`TXE`/`RXNE` state machine with `AF` NACK, `BTF` completion flags, repeated start mid-transfer, 10-bit headers (`11110xx0` + second byte, `11110xx1` at once), clock-stretch stimulus bit, event/error IRQ lines. Deliberately unmodeled: slave mode, receive overrun (unreachable — the clock stretches instead), `ARLO`/`BERR`/`PECERR`. EEPROM-proven with real C firmware on `f103` (random read with `Sr`, `BTF` snapshot, 10-bit header, wire-byte drain — `i2c_eeprom.rs`)
- `ADC` sampling core: `SCAN`/`CONT`/single sequences over `SQRx`/`CHSELR`, injected group (`JSWSTART`/`JAUTO`, `JDRx`, `JEOC`), analog watchdog (`AWDEN` + `HTR`/`LTR`, `AWD` + IRQ), external triggers (`EXTTRIG`/`EXTEN`, `JEXTTRIG`/`JEXTEN` via stimulus edges), per-channel stimulus levels, `EOCIE`/`JEOCIE`/`AWDIE`/`OVRIE` lines, DMA requests, dual-mode common state. Deliberately unmodeled: discontinuous (`DISCEN`) mode. Scan/watchdog/injected-proven with real C firmware on `f103` (distinct per-channel codes, `AWD` trip, `JDR1` — `adc_scan.rs`)
- `DAC` output paths: immediate/DMA/SW-trigger latch plus `WAVE` triangle (counter within the `MAMP` mask, added to `DHR`) and noise (12-bit LFSR, documented taps) generators; converted codes publish to the analog bus when wired, feeding `ADC`/`COMP` chains. `COMP` follows the bus with hysteresis (`OUT`/`VAL` + `IF` IRQs on `H7`; `F0` routes through `EXTI`, unmodeled). `OPAMP` stays enable→ready. Triangle/chain-proven on `f103` plus hysteresis-proven on `f042` with real C firmware (`dac_wave.rs`, `comp_hyst.rs`)
- `RTC`/`BKP`: F1 prescaler/counter/alarm calendar (`CNF` protocol, `SECF`/`ALRF`/`OWF`, `RTC` + `RTCAlarm` lines) and new-gen calendar (`TR`/`DR`, alarm A, `WPR`/`INIT`); backup registers survive system reset, tamper events (stimulus bit) latch `TEF`, wipe the data registers, and raise `TAMPER` via `TPIE` (`CTEF` clears). Deliberately unmodeled: `PWR.DB` write protection, `RCC.BDCR` backup resets, wakeup timer, alarm B. Alarm-IRQ + cross-reset persistence proven with real C firmware on `f103` (`rtc_alarm.rs`)
- `IWDG`/`WWDG`: independent watchdog (`KR` keys, prescaler, reload, shared reset latch) and window watchdog (counter loads from `T`, window-checked refresh, underflow reset, `EWIF` + `EWI` early interrupt on IRQ 0) clocked on `PCLK/4096` divided by `2^WDGTB` — the base prescaler keeps the `EWI`→underflow gap wide enough for the handler. Reset-observed with real C firmware on `f103` (`EWI` through the NVIC + reboot counters for both watchdogs — `wdg_reset.rs`)
- `CRC`: fixed units compute CRC-32/MPEG-2; programmable units (`POL`, `POLYSIZE` 32/16/8/7, `REV_IN`, `REV_OUT`, `INIT`) feed bus transactions MSB-first through the `S`-bit engine (byte/halfword/word paths, sub-word polys documented). Proven by 6 exact check values (MPEG-2, ISO-HDLC, CCITT-FALSE, CRC-8, CRC-7, `INIT` reload) + real C firmware on `g474` (`crc_vectors.rs`)
- `RNG`: `DRDY` data path with deterministic xorshift stream, health monitoring (`CECS`/`SECS` latch and halt, `CEIS`/`SEIS` mirrors, single IRQ line, write-0 clear and disable recovery, `CED` detection switch), SVD-resolved offsets. Deliberately unmodeled: true entropy (deterministic by design), startup latency, conditioning internals. Statistical smoke (distinct + balanced + rerun-identical) plus flag checks in lib tests, board-level smoke on `h743` (`rng_smoke.rs`)
- `DMA`: F1 channels (`MEM2MEM` optimistic copy, `CIRC` reload, `PINC`/`MINC`, widths, `GIF`/`TCIF`/`HTIF`/`TEIF` + enables, `PL` arbitration) and F4 streams (request-paced bursts, `CIRC`/`DBM`/`CT`, FIFO + `FTH` + `FEIF`, `DMEIF`, per-flag IRQs, DMAMUX routes), TIM/ADC/SPI/USART request wiring. MEM2MEM + circular proven with real C firmware on `f103` (`dma_flow.rs`); request pacing proven per-board (`f2_clock_dma.rs`)
- `USB` OTG host: `HPRT` port machine (power/connect/SOF-counted reset/enable), SOF scheduler (`HFNUM`, periodic interrupt/isochronous deferred to the frame boundary), channel execution (control SETUP/data/status, bulk/interrupt/isochronous IN/OUT, `HCTSIZ` write-back, `ACK`/`NAK`/`STALL`), split start/complete sequencing via `HCSPLT` (`OTG_HS` only — no `HCSPLT` in any `OTG_FS` table, unsplit there). Virtual devices: CDC-ACM (`new`) and HID boot keyboard (`hid_keyboard`: HID/report descriptors, idle/protocol/report/LED requests). Deliberately unmodeled: hub topology and hub-class descriptors (STALL), high-bandwidth microframe scheduling. HID enumeration + key-report + LED traffic proven on `f407` `OTG_FS`, split start/complete pairs on `OTG_HS` (`usb_host_hid_split.rs`)
- `ETH` H7 full: TX frames chain across `FD`..`LD` descriptors (one `TI` per frame) and RX frames scatter across consecutive owned descriptors (all-or-nothing, `RBU` otherwise); checksum offload inserts IPv4 + TCP/UDP/ICMP checksums per `TDES3.CIC` (pseudo-header for `CIC=3` on TCP/UDP) and validates them under `MACCR.IPC` with `RDES1` `IPCB`/`IPHE`/`IPCE` + `RDES3.ES` write-back (flagged frames still delivered; FCS unmodeled); MMC TX-good/unicast-RX packet counters increment where the table carries them. Deliberately unmodeled: VLAN/TSO contexts, MTL queues, MMC control/interrupts, PMT wakeup (single `ETH` line). Large-payload UDP echo with wire-verified checksums + scatter + error-flag + MMC proof (`eth_h7_checksum_mmc.rs`)
- Display/camera: LTDC layers with immediate/blanking reload (`RRIF`), line-position IRQ against a scanline counter (`TOTALH + 1` lines/frame, live `CPSR.Y`); DMA2D register fills + memory copies with pixel-format conversion over a bus mailbox (flag-only without one, `TEIF` on blend/CLUT formats, `CAEIF` on abort, line watermark); DCMI snapshot bytes out of `DR` plus frame flag; JPEG stays handshake-only (no codec). Deliberately unmodeled: pixel pipelines/blending, DSI (no SVD/panel), DMA-linked capture, JPEG coding. Proven by board-level frame-IRQ e2e on `h743` (`display_frame_irq.rs`)
- Analog extras, in firmware-demand order: SAI per-block TX/RX FIFOs with `MCKDIV` frame rhythm, `FREQ`/`FLVL` levels, overrun/underrun and RX mute-detect flags; DFSDM channel/filter enables with regular/injected conversions of the shared bus (offset binary, `FOSR`-paced) plus analog watchdog and per-filter lines; OPAMP followers/amplifiers with field-scanned modes/gains publishing to the bus (rail-clamped, change-gated so followers never self-amplify); SPDIFRX sync handshake with staged data and parity errors. Deliberately unmodeled: SAI slots/sync/mono/mute-TX/DMA, DFSDM DMA/breaks/extremes, OPAMP cal/lock/`VP_SEL`, SPDIFRX biphase decoding/channel data/overruns/DMA. Proven by a DAC→OPAMP→ADC→DFSDM bus chain plus SAI/SPDIFRX legs on `h743` (`analog_extras.rs`)
- Radio honesty (documented-virtual stance, no RF physics): the shared packet engine frames every air frame as `LEN | ADDR? | PAYLOAD | CRC?` — node-address filtering (sync-word-like network address, silent drops) and CRC-16/CCITT-FALSE verify (`SR.CRCERR` + `DROPSTAT` counter), parsed from the byte stream with split-delivery reassembly; link parameters must match on both ends. Deliberately unmodeled: `SUBGHZSPI` commands, BLE CRC-24/access-address/whitening/channels, collisions/arbitration, RSSI/timing. Proven by loopback + two-peer + three-machine filtered delivery with drop counts (`radio_peer.rs`, `radio.rs` lib tests)
- `FSMC` bank configuration with gated external windows: `BCRx`/`BTRx`/`BWTRx`/`PCRx`/`PMEMx`/`PATTx` latch from the tables, `SRx.FEMPT` reads set (no transfer engine), and the bank regions gate on `MBKEN`/`PBKEN` (enabled floats `0xFF`, disabled faults `Reserved`). The control window is trimmed to its register span (value-line tables grant `0xfffff400`, which shadowed the core block). Deliberately unmodeled: NAND/PC-card transfers, ECC (`ECCR` reads zero), wait timing, the IRQ. Proven by reset/config/gating lib tests plus board-level gating (`f103`, `f100` with DWT/SysTick reachability guards)
- `I2C` runs both generations: the F1 engine (repeated start, 10-bit, `BTF`, stretch) plus a new-generation path for F0/F3/L0/L4 tables (`TIMINGR`/`ISR`/`ICR`/`RXDR`/`TXDR`), detected per instance — `CR2` transfer descriptors, `ADDR`/`TXIS` vs `NACKF`, per-byte ready flags, `TC`/`STOPF`, `ICR` clears, `TIMINGR`-paced bytes. Deliberately unmodeled on the new path: 10-bit, `RELOAD`, SMBus/PEC/DMA. Proven by 6 F0-table lib tests plus peerless-NACK wiring proof on `f030` (`f030_closeout.rs`)
- `DBGMCU` identification: board-documented `IDCODE` (`0x10000444` on `f030`: RM0360 §26.4.1), `CR`/`APBxFZ` latches (freezing is meaningless in virtual time)
- `TSC` touch acquisition and `CEC` transmit handshake: `TSCE|START` latches `ISR.EOAF` next tick (cleared by `ICR`); F0 `CECEN` + `TXDR` latches `ISR.TXEND` next tick (write-1-to-clear), F1 `TXD` + `TSOM` latches `CSR.TEOM` with `TSOM` self-clearing (plain-write clears). Deliberately unmodeled: charge-transfer counts, CEC arbitration/RX/errors. Proven by F0 + F1 lib tests plus board-level handshake tests (`f031`/`f042`/`f072`/`f091`/`f0xx`, `f100` for F1)
- Crypto completion: AES GCM/GMAC/CMAC over the hand-rolled FIPS-197 core — GHASH engine, `GCMPH` phases (init/header/payload/final, classic `[17:16]` vs U5 `[14:13]` by table, `NPBLB` pad count), 96-bit IVs, CMAC subkeys with K1/K2 + `10*` pad (U5 only), `SUSPR0-7` save/restore of chain/counter + tag accumulator; HASH HMAC-SHA1/224/256 by the HAL two-step key/message `DCAL` flow (`LKEY` hashes long keys first) over an incremental streaming core, `CSR0-53` suspend/resume of plain streams (HAL save/restore shape, mid-HMAC swap out of scope). Deliberately unmodeled: MD5/HMAC-MD5 (zeroed), empty CMAC (inexpressible in `NPBLB`), non-96-bit GCM IVs, data-phase `DLEC`, timestamps, DMA lines, key hiding. Proven by NIST vectors per mode — GCM Cases 1-3, GMAC-empty, Case-4 AAD cross-checked vs an independent GCM, CMAC Ex2-4, RFC 4231 HMAC (incl. 131-byte key) + HMAC-SHA1/224, suspend/resume round-trips — in `aes.rs`/`hash.rs` lib tests plus board proofs on `u585`/`u575` (`crypto_boards.rs`)
