# Host I/O

- `Peripheral::drive_inputs` / `drain_output` for CAN/ETH/USB/SDIO/DAC etc.
- `DmaRequests` mailbox for USART/SPI/ADC/TIM, `EthMailbox`, `Sdio` card image.
- `QspiGate` for `0x90000000` via `QUADSPI CR.EN`.
- Semihosting: `vioarm run fw.elf --semihost` arms `BKPT 0xAB` (`WRITEC`/`WRITE0`/`WRITE` fd 1/2 → `semihost:` output, `READC` from queued input, `EXIT` → `semihost exit(code)` halt). Disabled by default, so `BKPT` keeps faulting for QEMU parity.
- ITM: writes to stimulus ports (`0xE0000000`, `TER` `0xE0000E00`, `TCR` `0xE0000E80`) queue into the `itm:` channel on every board; drain with `Machine::drain_channel("itm")`.
- RTT: `Machine::rtt_poll(ram_base, ram_len)` drains target→host bytes on channel 0 (scans for `SEGGER RTT` once, ring offsets wrap at size), `rtt_inject` feeds channel 0. Virtual timebase is `cyccnt` at 1 MHz (`TICKFREQ`), so `CLOCK`/`ELAPSED` are deterministic.
- Hooks (`Machine::on_instruction`/`on_read`/`on_write`/`on_peripheral`): pre/post-instruction callbacks over a PC range, byte-granular memory watchpoints, and peripheral-access events by device name. Callbacks observe only (no machine handle — reentry is impossible by construction). With nothing armed the cost is one predicted branch per step/access (measured 2.4% worst-case, `BENCHMARKS.md`). `Coverage` rebuilds basic blocks from retired PCs (`cargo run -p vioarm-core --example coverage`). CLI: `vioarm trace fw.elf --format jsonl [--output trace.jsonl]` streams `{"cycle","pc"}` per retired instruction. Rust API only, deliberately no `.so` plugin ABI.
- Fabric (`Fabric`, `link_uart`, `link_can`, `link_spi`, `link_radio`): two or more machines stepped in lockstep (index order, no threads) with virtual wires pumped every round — UART TX bytes drive the peer RX both ways; CAN TX frames arbitrate lowest-identifier-first onto every other member (own filters apply); SPI pairs exchange controller MOSI for peripheral MISO staging with one round of pipeline delay (slave: `SPE` without `MSTR`, `SSM` recommended); radio bytes broadcast to every other member. `Machine::drive_device`/`drain_device` move bytes by device name. Reruns are byte-identical (own `cyccnt` per machine; lockstep is step-granular, not cycle-exact across machines).
- Replay (`vioarm record`/`replay`, `replay.rs`): golden traces collapse to image + config re-executed (single-threaded determinism needs no checkpoints). `record` captures image digest, halt, counters, drained channels, and RAM-span digests into git-diffable `vioarm-golden-v1` text; `replay` re-runs and diffs (exit 1 on any difference), with `--patch ADDR=VAL` standing in for a mutated model. Default span is 4 KiB at `0x20000000`; repeat `--snap BASE:LEN` for more.
- pytest (`pytest/`, CI `pytest` job): `vioarm_harness.py` template (build C → run board → assert drains, record/replay helpers), `test_usart_tx.py`, `test_replay.py` (no toolchain), `ROBOT_KEYWORDS.md` catalog. Run with `VIOARM_BIN=$PWD/target/debug/vioarm-cli pytest pytest/`.
- Radio (`radio.rs`, `ble.rs`, `Fabric::link_radio`): virtual link-layer endpoints — SUBGHZ packet mode on WL boards (extends the `CR`/`SR` stub), BLE advertising on `wba55` (documented-virtual window; real BLE is CPU2/IPCC). `TXDATA`/`TXGO` transmits, `RXSTAT`/`RXDATA` receives, `LOOPBACK` echoes without a peer; the fabric radio bus broadcasts to every other member. No RF physics, access-address, CRC, or PHY by design.
