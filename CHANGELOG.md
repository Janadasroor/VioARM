## [Unreleased] — v2.0 production (500 alias→real)
### Added
- **Waveform export: `vioarm trace --format vcd`** (WP-R1): value-change dump of the 32-bit `pc` bus plus `--pin-log` pins sampled every `--pin-sample` steps, with board-clock-true `#ns` timestamps (integer `cycles·1e9/hz`), change-only rows, and a fixed `$date` so reruns are byte-identical; opens directly in a waveform viewer. Proven by 5 CLI unit tests (header, change-once rows, steady-state silence, rerun identity, clock scaling) and a board-level `stm32f103` run diffed across reruns.
- **Fault backtrace ring + `debug history` (WP-R2)**: `Machine` records the last 256 retired `(pc, opcode, cyccnt)` by default (`Machine::set_backtrace(len)`, `0` disables; `reset()` clears the ring but keeps capacity); fault halts in `run`/`trace`/`debug` print the last 32 as `pc op cyccnt` after the halt line (the faulting instruction never retires, so the ring is the prefix and the live `pc` names the site), and the `debug` REPL gains `history [N]`. Opcode halfwords are re-read at render (self-modifying code shows current bytes); 32-bit Thumb-2 prefixes pair with their second halfword, narrow opcodes print alone. Under `--jit` only stepper fallbacks record, so rerun without it for full depth. Overhead within run-to-run noise (200k-step NOP/branch probe: −2.3%, i.e. no measurable regression). Proven by 5 core ring tests (order/opcodes/time, capacity bound, disabled, reset-clears-keeps-cap, assembler-verified fault prefix) plus 3 CLI format tests.
- **Field benchmark subcommand: `vioarm benchmark` (WP-R3)**: measures stepping throughput on the machine in front of you — `bare-nop` (1k NOPs on bare `FlatMemory`, the `mips/nop_loop_1k` twin), `board-boot` (vector-table boot at the flash alias, 10k NOPs per window, family-correct core, the `board/stm32f103_boot_10k_nop` twin), and `usart-tx` (F1-map `CR1=UE|TE` + 200 `STR`-to-`DR` soak with drained-byte accounting). Prints plain `kernel mips wall-ms cyccnt [# note]` rows (setup/reboots outside the timer, like `iter_batched`); `--cycles N` scales retired steps per kernel, `--board` switches the board kernels, `--fail-under <mips>` exits 1 on a missed CI floor. `usart-tx` resolves USART1 from the board's SVD table and skips cleanly where the F1 map is absent (e.g. `virtual`). Docs page at `docs/src/benchmark.md`. Proven by 5 CLI tests (row shape, window accounting, hand-encoded-firmware TX validation, floor logic, USART1 resolution).
- **Shared analog bus: one voltage, many consumers (WP-R4)**: host-owned `AnalogBusState` (exact millivolt `u32`, no physics; starts unset so consumers fall back to legacy digital paths), pre-installed in every `SystemMemory` (`analog_handle`/`set_analog_millivolts`, `Machine::analog_drive_mv`/`analog_mv`). ADC samples the bus at conversion-complete (`mv_to_adc_code` vs `VDDA 3300`), COMP derives its output from the bus vs `1650±50` hysteresis, GPIO F1/F4 and EXTI apply the `2000/800` Schmitt path, TIM external-clock mode (`SMCR.SMS=111`) counts bus-derived TI2 rising edges instead of the prescaler (digital TI ignored there, single-driver convention); `Apin` receipts publish into the bus so the transport feeds every consumer. Wired on `virtual` (`Apin`), `stm32f103`, and `stm32f303xe`; also fixes EXTI never forwarding `tick` (bus edge-latch was dead). Proven by 6 lib tests (ADC bus-wins, COMP hysteresis both directions, GPIO F1 Schmitt+analog-reads-zero, GPIO F4 input/alternate, EXTI edge+pending, TIM edge-count+digital-ignore) and 3 `analog_bus` e2e (production-F103 ramp: ADC tracks/GPIO follows/EXTI latches/TIM counts in one run, rerun byte-identical, Apin-transport-to-ADC).
