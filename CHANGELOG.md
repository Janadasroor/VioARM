## [Unreleased]

### Added
- **TI datasheet fetching (`scripts/fetch_ti_datasheets.py`, `datasheets/`, gitignored)**: official TI PDFs `SPMS376E` (TM4C123GH6PM, Rev. E) + `SPMS433B` (TM4C1294NCPDT, Rev. B) fetched from ti.com at runtime like the CMSIS packs — same CLI shape (`--list`, single-name, `--force`), skip-if-present with pinned SHA256. Never committed. These are the only two TI datasheets cited anywhere in the code.
- **SVD parser depth-guard (`vioarm-svd/src/svd.rs`)**: builder elements now record their nesting depth so scalar element text assigns only to direct children — a nested `<enumeratedValue><name>` (or cluster name) can no longer clobber the enclosing field/register name. `<addressBlock><size>` keeps an explicit carve-out (legitimately nested below the peripheral). New regression test `enumerated_value_names_do_not_override_field_names`; all 45 committed tables still regenerate byte-identically (gate green).
- **xtask `packs` subcommand + cargo alias**: new workspace member `xtask` and `xtask = "run -p xtask --"` alias, so `cargo xtask packs --fetch/--verify` drives `scripts/fetch_packs.py` (the previous stale prints — `16 DFP`/`577 Dnames`/TM4C hint — corrected).

### Changed
- **18 SVD tables regenerated** with the depth-guarded parser: `stm32f407`, `stm32g050/g061/g081/g0c1`, `stm32h503/h533/h563/h743`, `stm32l476`, `stm32u535/u575/u5g9`, `stm32wba55`, and the five TM4C dice. Diffs are name-only (killed `B_0x…`/`WDT_LOCK_*` pseudo-fields and similar nested-name bleed); no offset/width/base/window/count/register changes; the 27 enum-free tables are byte-identical.
- **Frozen board count 511** (was 507) in `pytest/abi_conformance.c` and `docs/src/embedding.md`; per-dname anchor `40204`.
- **Pack pinning/repair (`scripts/fetch_packs.py`)**: F7 (`74d3664b…`) and G0 (`6545f547…`) SHA256 pins added; relative `CMSIS/SVD` symlink with repair logic so all 13 DFP links resolve (no silent skip).
- **WBA55 HASH is now behavioral, not a latch**: the cleaned register names let the CR-map probe match (`stm32wba55` is contiguous `ALGO` at the U5 shift, identical CR map), proven by a NIST SHA-256 vector on its tables (`SHA-256("abc")[0] == 0xba7816bf`); `stm32wba55` boards gain real HASH (`layout_matches`), test renamed `probe_accepts_u5_wba_and_rejects_h5`.
